## Name

Off-Peak Tray

## Summary (short)

System-tray indicator for LLM provider off-peak/peak discount hours, with
boundary notifications.

## Description

Know at a glance when your LLM providers are charging discounted rates.

Off-Peak Tray is a Plasma 6 system-tray widget driven by a simple JSON file
(`~/.config/offpeak-tray/schedules.json`). Each schedule describes a
provider's published discount window — either the *peak* window (surcharges,
e.g. Z.AI GLM's Mon–Fri 14:00–18:00 Singapore time) or the *off-peak* window
(discounts, e.g. Qwen's nightly 22:00–08:00 Beijing time). Windows can cross
midnight and are computed in the provider's timezone, so US daylight saving
never shifts them.

Features:

- Tray icon states by share of schedules currently discounted: green clock +
  `$` badge (all), split green/red clock (some), red clock (none)
- Detail popup with one bordered row per schedule: current state, the next
  state change in your local timezone (am/pm), a per-provider state
  inventory, and a free-text discount note
- A dynamic "Combined off-peak" row: the intersection of all your discount
  windows — when *everything* is cheap at once
- Click a row to open that provider's pricing documentation
- Optional boundary notifications: a systemd user timer per window edge fires
  a desktop notification when a window opens or closes (generated by the
  bundled installer)

Install: unzip via *Get New Widgets*, then run
`python3 scripts/offpeak.py install` from the source repository to seed the
default config and enable the notification timers (the widget itself works
without this step and shows a config hint until
`~/.config/offpeak-tray/schedules.json` exists).
